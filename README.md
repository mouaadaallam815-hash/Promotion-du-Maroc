# Promotion du Maroc — نسخة أولية

## التشغيل
- افتح `index.html` في المتصفح للتجربة.
- للحصول على تجربة PWA والتخزين المؤقت، ارفع الملفات إلى استضافة HTTPS مثل GitHub Pages.
- يمكن ضغط المجلد كاملاً ورفعه إلى مستودع GitHub.

## ما تحتويه النسخة
- أقسام الأسواق الكبرى، المحروقات، الاتصالات، والعقار.
- البحث والتصفية حسب المدينة.
- تفاصيل العروض داخل التطبيق.
- لوحة محلية لإضافة العروض يدوياً وتحديث أسعار البنزين والغازوال مع المصدر والتاريخ.
- تصدير واستيراد بيانات JSON.
- واجهة قابلة للتثبيت عند استضافتها على HTTPS.

## حدود مهمة
- لوحة الإدارة والتخزين محليان في المتصفح والجهاز الحالي فقط؛ ليسا نظام إدارة آمناً متعدد المستخدمين.
- لا يوجد حتى الآن جمع تلقائي من المواقع، ولا قاعدة بيانات أو حسابات إدارية. يلزم خادم أو Backend، ومراجعة شروط المواقع وواجهات API المرخصة قبل إضافة الجمع التلقائي.
- البطاقات الثلاث الافتراضية أمثلة تصميمية وليست عروضاً حقيقية. لا تنشرها على أنها عروض مؤكدة.
- لا تعرض أسعار محروقات حقيقية قبل إدخال بيانات موثقة مع المصدر وتاريخ التحقق.
- ترجمة الواجهة الفرنسية في هذه النسخة جزئية؛ ينبغي استكمال ترجمة جميع نصوص الواجهة قبل النشر العام.
